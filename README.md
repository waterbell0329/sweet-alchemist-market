# Sweet Alchemist Market — Classroom Command Center

인도네시아 초등학교 4학년(22명)·6학년(30명) 대상 75분 오프라인 경제 보드게임의 **교실 전광판 웹앱**입니다.
서버·로그인·DB·인터넷 연결 없이 동작하며, 수업 상태는 브라우저 localStorage에 저장됩니다.

## 실행 방법

### A. 설치 없이 바로 쓰기 (교실용 추천)
`dist-single/index.html` 파일 하나를 더블클릭해서 Chrome/Edge로 엽니다. 인터넷이 없어도 됩니다.
(폰트·코드가 모두 파일 안에 들어 있습니다.)

### B. 개발 환경
```bash
npm install
npm run dev          # http://localhost:5173
npm test             # Vitest 핵심 로직 테스트 (77개)
npm run build        # dist/ 프로덕션 빌드
npm run preview      # 빌드 결과 확인 (http://localhost:4173)
npm run build:single # dist-single/index.html 단일 파일 다시 만들기
```
Node 18 이상 필요 (Node 22에서 검증).

## 교사 사용 순서
1. 전체화면(⛶ 또는 `F`) → 학년·언어 선택 → 튜토리얼 5장 설명 (1차 투자는 이때 미리 접수 가능)
2. **시작**(`Space`) → 75:00부터 카운트다운
3. 정해진 시각에 알림이 순서대로 뜸: 투자 마감 → [예치 확정], 추첨 가능 → [가챠 머신으로] → **SPIN**
4. 상점 가격은 각 재료의 `할인 1 / 정상 2 / 품귀 4` 버튼, 돌발 뉴스는 📰 메뉴
5. 15:00 Last Call, 10:00 마켓 마감, 00:00 종료 → 🏆 시상식에서 수상자 입력 후 [발표!]

수업 중 실수로 누르면 안 되는 버튼은 🔒 **버튼 잠금**으로 막을 수 있고, 👁 **관람 모드**(`H`)는 교사용 버튼을 모두 숨깁니다.

## 단축키
| 키 | 동작 | 키 | 동작 |
|---|---|---|---|
| Space | 시작/일시정지 | L | 언어 전환 |
| + / − | 남은 시간 +1분 / −1분 | M | 음소거 |
| N | 다음 단계 (확인창) | F | 전체화면 |
| S | SPIN | H | 관람 모드 |
| Enter | 알림·결과 확인 | T | 튜토리얼 |
| ← / → | 튜토리얼 이전/다음 | Esc | 창 닫기 |

## 구현 기능
| 영역 | 내용 |
|---|---|
| 타이머 | 벽시계 기준 앵커 방식(드리프트 없음), 0~4500초 클램프, ±1분, 다음 단계(65:00→15:00→10:00→00:00), 00:00 자동 정지 |
| 이벤트 스케줄러 | `src/data/events.ts` 중앙 스케줄. 한 번만 발동, 되감기 시 재발동 없음, 점프로 건너뛴 이벤트는 대기열 표시, 같은 시각은 우선순위(투자 → 뉴스) 순 |
| 투자 | 5라운드(모집 10분 → 마감 → 10분 대기 → 추첨). 상태: 모집 전/모집 중/예치 마감/10분 대기/추첨 가능/추첨 중/추첨 완료 |
| 가챠 | `crypto.getRandomValues` + 거부 샘플링으로 0~99 균일 난수 → 0–14/15–34/35–64/65–89/90–99. 결과 확정 후 2.5초 애니메이션. 일괄(라운드당 1회)·개별(학생 번호, 중복 경고, 무효 처리 후 재추첨) |
| 상점 | 기본가/수동가/뉴스 오버레이 분리. 뉴스 > 수동 > 기본 우선순위, 뉴스 종료 시 이전 가격 복원, 가격 변화 화살표·색상 애니메이션 |
| 뉴스 4종 | 카카오 대풍년(40:00 자동, 5분), 치즈 품귀(25:00 자동, 종료까지·취소 가능), 연금술사(수동, 3분), 타임세일(수동, 10:00까지). 지속시간은 게임 시간 기준 → 일시정지 시 멈춤 |
| 다국어 | ko / id / 병기(인니어 크게 + 한국어 보조). `translate(lang, key, params)`, 복수형, 누락 키 감지(콘솔 경고 + 테스트). 기록·팝업도 즉시 재번역 |
| 저장 | 버전 포함 키 `sweet-alchemist-market:v1`, 필드별 검증, 손상 시 새 게임으로 복구. 새로고침하면 항상 일시정지 상태로 복원(닫혀 있던 시간은 진행 안 함). 추첨 중 새로고침해도 결과 유지 |
| 사운드 | Web Audio 합성 11종(클릭·비프·사이렌·드럼롤·수익·팡파르·잭팟·파산·속보·마감·시상). 첫 클릭 시 활성화, 컴프레서로 음량 제한, 실패해도 게임 정상 동작 |
| 화면 | 1920×1080 캔버스를 창 크기에 맞춰 비율 유지 확대/축소 → 어떤 해상도에서도 스크롤 없음. 확인창(초기화는 2단계), 토스트, 키보드 포커스, `prefers-reduced-motion` 지원 |

## 설계상 결정
- **+1분/−1분은 "남은 시간" 기준**입니다(+1분 → 시계가 1분 늘어남).
- 투자 "예치 마감"은 교사가 알림의 [예치 확정]을 누르면 "10분 대기"로 바뀝니다. 추첨 시각이 되면 자동으로 확정 처리됩니다.
- 알림 창의 [나중에]로 잠시 숨길 수 있고, 🔔 버튼으로 다시 엽니다.
- 일괄 추첨 결과 기록은 "1 Gold 기준"으로 저장하고, 결과 창에 1~4 Gold 반환표를 함께 보여줍니다.
- 앱은 학생별 코인 잔액·레시피 소유를 추적하지 않습니다(명세대로 교사가 실물 확인).

## 제한사항
- 헤드리스 브라우저에서는 소리를 직접 들어볼 수 없어 **효과음은 실제 기기에서 한 번 확인**이 필요합니다.
- 브라우저 정책상 첫 클릭 전에는 소리가 나지 않습니다(헤더에 안내 표시).
- 데이터는 해당 브라우저의 localStorage에만 있으므로 다른 PC/브라우저로 옮겨지지 않습니다.
- Windows는 국기 이모지를 표시하지 못해 언어 버튼은 `KO / ID / KO+ID` 텍스트로 표시합니다.
- 디버그용으로 브라우저 콘솔에 `window.__samStore`(게임 상태)와 `window.__i18nMissing`(누락 번역)이 노출됩니다.
